# StudySync — Task 3: High-Fidelity UI/UX Prototype

A responsive, high-fidelity student study planner prototype built with HTML, CSS and vanilla JavaScript.

## Included deliverables
- `index.html` — three connected application screens: Dashboard, My Tasks and Progress Insights.
- `styles.css` — responsive purple-and-white visual system, components, cards, charts and mobile layouts.
- `app.js` — working navigation, task creation, completion, deletion, search, category/status filters and browser local storage.
- `DESIGN_SPECIFICATION.md` — design rationale, tokens, components, screen descriptions and interaction notes.
- `screens/` — SVG design exports for all three key screens (open in a browser or design tool).
- `SUBMISSION_CHECKLIST.md` — final hand-in checklist.

## Run the prototype
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge or Firefox.
3. No installation or build process is required.
4. Add a task, mark it complete, delete it, and test the search and filters. Refresh the page to confirm tasks persist in browser local storage.

For best results, use a desktop viewport around 1440 × 900, then test the responsive layout on a mobile viewport around 390 × 844.

## GitHub upload
Create a new repository named `StudySync-UI-UX`, extract this folder, then upload all files while preserving the folder structure. The GitHub Pages site can be enabled from **Settings → Pages → Deploy from a branch → main / root**.

## Notes
This is a front-end prototype using sample student data. Task data is stored locally in the browser and is not synchronized between devices or users. The charts and focus-time values are presentation/demo data.
